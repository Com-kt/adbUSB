# Contributing Guidelines

Thank you for your interest in the project. 

### 🚫 No Pull Requests Accepted
To maintain the architectural integrity and follow the original design goals of this project, I have decided **not to accept any external code contributions**. 

Please do not spend time writing code intended for this upstream repository, as it will not be merged.

### ✅ Encouraged: Fork and Modify
If you need specific changes or improvements, the best way forward is to:
1. **Fork** this repository.
2. Implement your changes in your own repository.
3. Maintain your version independently.

This approach allows you full creative freedom over your version of the project while keeping this core repository focused on its original roadmap.
